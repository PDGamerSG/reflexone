# ReflexOne

Trainable, calibrated decision models that turn text into structured predictions in one pass.

Inspired by the typed decision interface described in [TypeSafe's Jev introduction](https://typesafe.ai/blog/introducing-system-one-models-and-jev). ReflexOne is an independent, domain-specific implementation, not a reproduction of Jev's proprietary architecture or RLCD training.

The implementation and measured experiment reports are in progress. See the design and implementation plan under `docs/superpowers/` for the agreed scope.
